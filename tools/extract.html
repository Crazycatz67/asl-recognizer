Dataset extractor — Kaggle ASL alphabet → landmark vectors

  1. Download and unzip the Kaggle asl-alphabet dataset.
  2. Serve this repo over http://localhost and open this page.
  3. Pick the asl_alphabet_train folder below. Each letter is a subfolder (A/, B/, …, plus space, del, nothing).
  4. Run. When it finishes, download dataset.json and save it to data/dataset.json in the repo.

Max images per label controls the subsample. kNN needs only a few hundred per class; start at 150 for a fast dry run, raise later. Images where no hand is detected are skipped and logged.
